# とあるところに（サウンドノベル）

Termux + GitHub Actions ビルド前提のサウンドノベルアプリ。
外部依存ゼロ / XMLレイアウトなし / プログラマティックUI。

## 収録内容 (v4.4)
- 第一章「透編」全34話（誰でも読める）
- 第二章「篤史編」全28話（パスコード 8147 で解錠）
- 第三章「茜編」全27話（パスコード 3065 で解錠）
- 1話につき背景1枚（全22種）+ 環境音（全9種）
- タイプライター表示 / 6行ページ送り / 章ごとオートセーブ
- アイコン: 夜のキャンプコテージ

## 分岐とエンドコレクション (v4.1)
第一章に2つの分岐を追加。タイトルの「エンドコレクション」で取得状況を確認できる。

| 分岐 | 場所 | 選択肢 | 結果 |
|---|---|---|---|
| 分岐1 | 第二話 駅に降りた直後 | 宿を探す | 正規ルート（続行） |
|  |  | 駅で一晩明かす | 透エンド1「普通の大学生活」 |
| 分岐2 | 第四話 梨花が見当たらない | 探す | 正規ルート（続行） |
|  |  | 今日は寝る | 透エンド2「気まずい2人」 |

| 分岐3 | 第九話 コテージを見つけた | 訪ねる | 正規ルート（ep09b へ） |
|  |  | 怪しいので見つかるまで探す | 崖ルートへ → さらに2択 |
| 分岐3-2 | 崖から落ちた後 | 戻ってコテージを探す | 正規ルート（ep09b へ合流） |
|  |  | 温泉に戻る | 透エンド2「気まずい2人」 |

選択肢は誤タップ防止のためカバーで覆われ、**下方向にスワイプ**すると現れる。

第一章を最後まで読むと「第一章 完／十分の一」も記録される（全3種）。
エンド到達時はエンドカードが表示され、初回は NEW ENDING 表示。
未取得のエンドはコレクションで ????? と伏せられる。

### シナリオ側の書き方
    {"t":"choice","q":"どうする？",
     "a":{"v":"宿を探す","goto":"ep02"},        ← 自分と同じ話IDなら「その場で続行」
     "b":{"v":"駅で一晩明かす","goto":"ep_endA"}}
    {"t":"ending","id":"toru1","label":"透エンド1",
     "name":"普通の大学生活","desc":"…"}
エンドを増やすときは ending ノードを置き、MainActivity.kt の allEndings に1行足す。

## 章とパスコードの仕組み
- タイトル画面のボタン: 「はじめから」「つづきから」「章を選ぶ」「人狼スマホのパスコードは？」
- | 分岐3 | 第九話 コテージを見つけた | 訪ねる | 正規ルート（ep09b へ） |
|  |  | 怪しいので見つかるまで探す | 崖ルートへ → さらに2択 |
| 分岐3-2 | 崖から落ちた後 | 戻ってコテージを探す | 正規ルート（ep09b へ合流） |
|  |  | 温泉に戻る | 透エンド2「気まずい2人」 |

選択肢は誤タップ防止のためカバーで覆われ、**下方向にスワイプ**すると現れる。

第一章を最後まで読むと、篤史たちの人狼スマホのパスコード **8147** が作中で明かされる
- タイトルの「人狼スマホのパスコードは？」ボタン、または「章を選ぶ」→ロックされた第二章をタップ
  → テンキーで 8147 を入力すると第二章が解錠される
- 解錠状態は端末に保存され、次回以降は「章を選ぶ」からいつでも読める
- 各章の進捗は独立してオートセーブされる（章ごとに「つづきから」が効く）

## 第二章のアナザーストーリー整合（第一章との矛盾修正済み）
- バスで「梨花」と名乗った女性は、本物の梨花とは別人（主催者側の協力者）
- 本物の梨花は第一章通り、透と電車で来て温泉ではぐれ、山道からコテージへ合流
- 透の来訪は第一章通り、道に迷い雨の中コテージの扉を叩く形（透を探す第三者は削除）
- 千鶴の「梨花」認識も、本物到着まで確定しない伏線に整理

## 話選択（開発・読み返し用）
第三章を最後まで読むと、「章を選ぶ」画面の下に「話を選ぶ」が解放される。
章タブで第一〜三章を切り替え、番号をタップするとその話から再生できる。
（manifest.json の chapters[].episodeList に話ID・タイトルを保持）

## セーブ / ロード (v4.4)
- 選択肢画面の最上部に「この分岐をセーブ」ボタン。カバーで覆われている間も押せる
- スロットは3つ。セーブ名は「章　話　選択N　MM/DD HH:MM」形式
  （その話に選択肢が複数ある場合のみ番号が付く）
- タイトルの「つづきから」でスロット一覧を開き、任意のセーブ地点から再開
- スロットとは別に「自動セーブ」枠もあり、最後に読んでいた位置から続けられる

## 開発用コード
パスコード画面で **9999** を入力すると、全章の解錠と話選択が即座に解放される。

## ビルド
push すると GitHub Actions が app-debug.apk を出力します。
（AGP 8.5.2 / Kotlin 1.9.24 / Gradle 8.9 / debug.keystore 同梱）

## シナリオ形式（assets/scenario/*.json）
    {"t":"title","v":"第○話　……"}  話タイトルカード
    {"t":"bg","v":"cottage_hall"}    背景切替（bg/名前.jpg）
    {"t":"se","v":"fire"}            環境音（se/se_名前.wav、stopで停止）
    {"t":"l","v":"本文1行"}          タップで進む1行（『』『«』始まりは青字）
    {"t":"p"}                        ページクリア
    {"t":"choice","q":"？","a":{...},"b":{...}}  2択分岐
    {"t":"goto","v":"epXX"}          次の話へ
    {"t":"end","v":"fin"}            章の完結（タイトルへ）

## manifest.json（章定義）
    {
     "novelTitle":"とあるところに",
     "start":"ep01",
     "chapters":[
       {"id":"ch1","title":"第一章　透編","start":"ep01","locked":false},
       {"id":"ch2","title":"第二章　篤史編","start":"ep2_01","locked":true,"passcode":"8147"}
     ],
     "episodes":[...]
    }
新しい章を足すときは chapters に1要素追加し、epファイルを置くだけ。

## 第三章「茜編」を足すとき
1. 本文をチャットへ貼る
2. ep3_01.json 〜 を生成、新背景を bg/ へ
3. manifest.json の chapters に第三章を追記（locked と passcode を設定）
4. 前章の作中でパスコードを明かす演出を入れる
