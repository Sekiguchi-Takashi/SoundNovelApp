# 2巻「とあるところに」を app2 として追加

既存の SoundNovelApp リポジトリに、2巻をWebView版アプリとして追加します。
**1巻（app/）には一切変更を加えません。**

## v2.1 第四章の人物と、姿の変化

三十年の時が流れる第四章に合わせ、同じ人物の別の姿を追加した。

### 姿の切り替え

梨花と篤史は、図鑑のカードを開くと姿を切り替えられる。

| 人物 | 学生 | 新入社員 | 後年 |
|---|---|---|---|
| 梨花 | 幼なじみだった頃 | 父の会社で企画を任される | 社長として会社を率いる |
| 篤史 | 求人に応募した頃 | 案内を受けて入社 | イベントを預かる側に |

未到達の姿は「？」で伏せられ、該当の場面を読むと解禁される。

### 素材

## v2.0 人物図鑑

登場した人物を、デフォルメ絵つきの図鑑で確認できるようにした。

### 仕組み

- 物語で**出会った人物だけ**がカードに現れる
- 未登場の人物はシルエットで「？？？」と表示される
- カードをタップすると紹介文が開く
- 読み進めると、その人物の**追加情報**が解禁される

### ネタバレへの配慮

紹介文は「その人物が初登場する時点で読者が知っていること」だけを書いた。

- 主催者が誰か、人狼が誰か、といった核心は書かない
- 苗字が判明する前に苗字を出さない
- 追加情報も、該当の場面を読んだ後にだけ現れる

例：透の紹介は「大学生。幼なじみの梨花と旅行に出かけた」から始まり、
交番の場面まで進むと「元ラグビー部のフォワード」が追加される。

### 画面の構成

| 場所 | 内容 |
|---|---|
| タイトル | 「人物」から、これまでに出会った人を見返せる |
| プレイ中 | 上部の「人物」ボタン |

出会った人数は「10 / 11 人」のように表示される。

### ボタンの整理

HUDが「手掛かり / 人物 / 自動 / 設定」の4つになった。
「状態」は設定パネルの中へ移動している。

### 素材

デフォルメ立ち絵 11点（各20KB前後、計約230KB）。

## v1.7 人物表示の切替

立ち絵を消して、背景と文章だけで読めるようにした。

### 「人物 / 背景」ボタン

上部のボタンで切り替える。設定は次回起動時も保持される。

| モード | 表示 |
|---|---|
| 人物 | 立ち絵あり（従来どおり） |
| 背景 | 立ち絵なし。テキスト窓が広がり、文字も大きくなる |

背景モードでは、テキスト窓が画面の33%→46%に広がり、
文字サイズも上がるため、小説として読み進めやすい。

### 長押しで一時的にUIを隠す

テキスト窓を長押しすると、その間だけ文字とボタンが消えて
背景と立ち絵だけになる。指を離すと元に戻る。
絵をじっくり見たいときに使う。

### ボタンの表示調整

ボタンが5つになったため、画面幅に応じてラベルを短縮するようにした
（例：「手掛かり」→「手掛」、「音 ON」→「音」）。
幅360pxの端末でも、すべてのボタンが画面内に収まる。

## v1.6 場所の切り替わりを整理

背景が語句の誤判定で頻繁に切り替わっていた問題を解消。
物語の進行どおりの区間で場所を固定した。

### 主な修正

- **第一章の冒頭は、電車を降りるまでずっと車内**
  車窓から見た温泉街（SC0007）や、途中駅のホーム（SC0003）でも
  背景は車内のまま。実際に降りる SC0010 でホームへ変わる
- 会話に出た単語（「山道で迷って」等）で場所が変わらないようにした
- 「手元（スマホ画面）」は場所ではないため、その場の背景を継続
- 場所名と背景IDの対応を全章で統一

### 場所の切替回数

| 章 | 修正前 | 修正後 |
|---|---|---|
| 第一章 | 46回 | 19回 |
| 第二章 | 16回 | 6回 |
| 第三章 | 25回 | 6回 |
| 第四章 | 11回 | 9回 |

物語の移動（車内→ホーム→温泉街→旅館→交番→山道→コテージ）に
沿った回数へ落ち着いた。

### 同席者の維持

透と梨花のように行動を共にする区間では、
名前が出ない場面でも立ち絵を消さないようにした。

## v1.4 音量を整えた

「駅や旅館の前で音量が急に大きくなる」問題を解消した。

### 原因

- 各音を**ピーク基準**で正規化していたため、曲ごとに体感音量が違った
  （最大 -10.8dB 〜 -18.4dB とばらつきがあった）
- BGMに脈打つ低音や撥弦音があり、曲中の音量差が 8dB あった
- 場面ごとにBGMが頻繁に切り替わっていた

### 対応

| 項目 | 変更 |
|---|---|
| 正規化 | ピーク基準 → **RMS（実効値）基準**へ。全曲を同一音量に揃えた |
| BGMの構成 | 打撃音・撥弦音を廃し、**持続する和音だけ**で構成 |
| 曲中の起伏 | 移動RMSで割り戻し、**8dB → 3dB以内**に平坦化 |
| 和音の繋ぎ | 等パワーのクロスフェード（重なりでの音量落ちを解消） |
| 曲の長さ | 30秒 → 41〜45秒。ゆったりした進行に |
| 切替頻度 | 孤立した切替と3シーン未満の区間を吸収。第一章で9回のみ |
| フェード | BGM 2.2秒 / 環境音 1.6秒かけて入れ替わる |

測定結果（平均音量）:
BGM 4曲すべて -25.2dB、環境音 -26〜-28dB で揃っている。

## v1.2 での修正（起動直後に落ちる問題）

「繰り返し停止しています」はネイティブ側のクラッシュだった。
原因を切り分けられるよう、次のように作り直した。

| 対策 | 内容 |
|---|---|
| 例外の可視化 | onCreate 全体を try/catch し、失敗時は原因を画面に表示する |
| テーマ変更 | `Theme.Black.NoTitleBar.Fullscreen` → `Theme.NoTitleBar` |
| 全画面化 | 失敗しても本体は動くよう分離（例外を握りつぶす） |
| 向き固定 | Manifest から外し、Kotlin 側で try 付きで指定 |
| WebView設定 | `allowFileAccessFromFileURLs` 等の非推奨APIを削除 |
| meta読み込み | 動的 script 生成 → `<script src>` の静的タグへ |

これで、万一まだ問題があっても**黒画面で落ちる代わりに
エラー内容が画面に出る**ようになった。

---

## 以前の対応（v1.1）

初版は 4.4MB の JavaScript を一括で読み込む作りだったため、
WebView がメモリ不足で落ちていました。次のように作り直しています。

| 対策 | 内容 |
|---|---|
| 画像を実ファイル化 | base64 埋め込みをやめ、`bg/` `ch/` `fx/` に WebP を配置 |
| データを章分割 | `data/ch1.js`〜`ch4.js`。開いた章だけを読み込む |
| 読み込み方式 | `file://` では XHR が CORS で塞がれるため、script タグ方式へ変更 |
| 起動時の負荷 | 初回は meta（6KB）＋第一章（86KB）のみ |

これにより起動時のメモリ消費が大幅に下がりました。

## 構成

```
SoundNovelApp/
  app/          1巻 サウンドノベル（ネイティブKotlin版）── 変更なし
  app2/         2巻 とあるところに（WebView版）── 今回追加
    src/main/assets/
      index.html        ゲームエンジン（28KB）
      data/meta.js      章・分岐・エンド定義（6KB）
      data/ch1〜4.js    各章のシーン（86/51/44/30KB）
      bg/               背景 20点（956KB）
      ch/               立ち絵 36点（1.8MB）
      fx/               演出 2点（260KB）
  debug.keystore
```

パッケージ名が違うため（`com.sekiguchi.soundnovel` と `com.sekiguchi.toaru`）、
端末には**2つのアプリとして並んでインストール**されます。
